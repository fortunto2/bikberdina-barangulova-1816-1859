# Ревизские сказки 1816 и 1859 годов: Бикбердина и Барангулова

Поимённый указатель жителей двух башкирских деревень Оренбургского уезда по
VII (1816) и X (1859) ревизиям: **2 371 человек, 295 записей дворов**, мужская
и женская половины листа. У каждой строки есть дело, кадр скана и двор, так что
к оригиналу можно перейти за минуту.

Источник: Национальный архив Республики Башкортостан, ф. И-138 (Оренбургская
казённая палата), оп. 2, дд. 145, 146, 161, 170, 704, 706. Сканы опубликованы
на сайте [Башархив](https://basharchive.ru/census/reviz/list_common/).

## Зачем это

Ревизская сказка расписывает деревню по дворам: глава, сыновья, внуки, жёны,
дочери, возраст на прошлую и на эту ревизию, кто умер и в каком году. Для
башкирской семьи это часто самый ранний документ, где предок назван по имени вместе с
отцом и братьями. Но сканы рукописные, а поиск по имени внутри дела невозможен:
нужно листать сотни кадров и знать, в каком деле нужная деревня.

Здесь эти дела уже прочитаны. Ищете Ирмяка Узбекова или чью-то жену Кунакбику —
находите строку, в ней дело и кадр.

## Колонки

`revizii-1816-1859.csv`, UTF-8, разделитель запятая.

| Колонка | Что это |
|---|---|
| `год` | год ревизии: 1816 или 1859 |
| `дело` | номер дела в ф. И-138, оп. 2 |
| `деревня` | как в документе, в именительном падеже |
| `юрта`, `кантон` | административное деление из заголовка сказки |
| `сословие` | у Барангуловой 1859 года отдельно записаны «башкиры дворянского происхождения» |
| `кадр` | номер кадра скана в деле на сайте; у дела 161 имя файла |
| `двор` | номер двора так, как он записан; у 1859 года «по прошлой ревизии / по этой» |
| `пол` | по половине листа или по слову родства |
| `имя` | имя и отчество-фамилия, **выделены скриптом** из записи |
| `кто_в_семье` | слова родства перед именем: «его сын», «жена Аллаяра» |
| `возраст_прежний` | возраст по прошлой ревизии (1811 для 1816 года, 1850 для 1859); `нов.` — родился после неё |
| `возраст` | возраст на эту ревизию или «налицо» |
| `год_смерти` | если в сказке отмечено, в каком году человек умер |
| `запись` | строка расшифровки целиком: по ней проверяется всё остальное |
| `карточка` | ссылка на карточку дела на сайте Башархива |

`(?)` после слова означает неуверенное чтение, `[…]` — утраченный или
нечитаемый фрагмент.

## Чего здесь нет

- **Женщин 2-й юрты Бикбердиной (1859).** В опубликованных кадрах дела 706
  только мужские страницы; по итогу документа женщин там 331.
- **Части женщин 6-й юрты (1859).** Прочитано 215 из 270, остальные в расшифровку
  не попали.
- **Остатка Бикбердиной 1816 года по делу 145.** Сказка продолжается на листах
  53 и далее, они не отсканированы.
- **В деле 170 — вторая копия той же сказки, что в деле 145**, а не новые люди:
  9 дворов Бикбердиной и один двор, который в деле 170 стоит под Ишмуратовой.
  Соответствие указано в колонке `двор`: «15 (= двор 2 дела 145)».
- **Трёх дворов на листе 40 дела 170** нельзя привязать к деревне: её название
  на листе 39, которого нет в сканах.
- **Ревизий 1795, 1811 и 1834 по этим деревням в фонде И-138 нет.** Проверено
  по всей описи фонда на сайте. Документы той же губернии есть в Объединённом
  государственном архиве Оренбургской области, ф. 98.

## Как это сделано

Сканы прочитаны в сентябре 2026 года ИИ-моделью (Claude) лист за листом;
спорные места перечитывались на увеличенных фрагментах, обе копии дела 145/170
сверены между собой. **Сплошной сверки человеком не было.** Это указатель для
поиска, а не публикация источника: найденное проверяйте по кадру.

Таблица собрана скриптом `parse.py` из рабочих расшифровок. Сами расшифровки с
комментариями в репозиторий не входят. Колонки `имя`, `пол` и возрасты
выделены эвристиками: у 10 строк имя не выделилось (в записи только «его сын»
или имя утрачено), у 37 строк нет возраста. Колонка `запись` всегда полная.

Ещё две вещи, которые стоит знать:

- **Сайт датирует дела 704 и 706 1850 годом.** По титульным листам это 1859 год,
  X ревизия.
- **Фамилий в нашем смысле здесь нет.** «Якуп Лукманов» значит «Якуп, сын
  Лукмана»; у его сына второе слово будет уже «Якупов». Устойчивая фамилия рода
  появляется позже, и ищут её по имени общего предка.
